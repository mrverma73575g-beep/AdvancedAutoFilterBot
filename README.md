# Advanced Auto Filter Telegram Bot

Features:
- Auto Filter
- IMDb Poster
- Netflix Style Buttons
- VIP Subscription System
- Force Subscribe
- Auto Delete
- Request System
- Premium UI
- Docker + Koyeb Support

## Setup

Rename `.env.example` to `.env`

Install:
```bash
pip install -r requirements.txt
```

Run:
```bash
python bot.py
```
